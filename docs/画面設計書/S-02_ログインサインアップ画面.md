## 認証連携（フロントエンド側）

バックエンドを含めた認証フロー全体のシーケンス図は[backendリポジトリ docs/API一覧.md](https://github.com/h-fujiwara-dev/ielts-creater-backend/blob/main/docs/API一覧.md#認証フロー)にある。本節はフロントエンド（Next.js）側の実装方針のみを扱う。

### 構成要素

- **NextAuth.js**: Cognitoプロバイダを設定し、Authorization Code + PKCEフローでログインを行う
- **セッション保存**: 取得したAccess Token / ID TokenはhttpOnly・暗号化Cookieに保存する（クライアントJSからは読み取れない）
- **保護ルート**: `middleware.ts`で未ログイン時に`(protected)`配下へのアクセスを`(auth)/login`へリダイレクトする
- **API呼び出し**: `lib/api-client.ts`がセッションからAccess Tokenを取り出し、`Authorization: Bearer <AccessToken>`ヘッダーを付与してbackend APIを呼び出す

### 実装メモ

- Cognito App ClientはTerraform（[infraリポジトリ](https://github.com/h-fujiwara-dev/ielts-creater-infra)）でconfidential clientとして構築される
- ログアウト時はNextAuthのセッション破棄に加え、Cognitoのグローバルログアウトエンドポイントも呼び出す
- Phase 1（ローカル開発）では認証を行わず固定devユーザーで動作させる。Cognito連携はPhase 2から有効化する（[ielts-createrリポジトリ docs/ロードマップ.md](https://github.com/h-fujiwara-dev/ielts-creater/blob/main/docs/ロードマップ.md)参照）
