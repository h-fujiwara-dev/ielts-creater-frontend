## 画面仕様

| 項目 | 内容 |
| --- | --- |
| 主要要素 | セクション選択（Reading/Listening）、トピック入力/選択、難易度選択、生成開始ボタン、生成中インジケーター |
| 主な操作 | 条件を選択し生成を開始する |
| 遷移先 | 回答画面（生成完了後） |

生成は非同期（202 Accepted + ステータスポーリング）。生成中はローディング表示を行う。詳細フローは[backendリポジトリ docs/API設計書/POST_question-sets.md](https://github.com/h-fujiwara-dev/ielts-creater-backend/blob/main/docs/API設計書/POST_question-sets.md)を参照。
