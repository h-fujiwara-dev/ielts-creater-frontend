# S-06 履歴一覧画面

- 更新日: 2026-08-09
- 関連文書: [画面一覧](../画面一覧.md) / [backendリポジトリ docs/API設計書/GET_attempts.md](https://github.com/h-fujiwara-dev/ielts-creater-backend/blob/main/docs/API設計書/GET_attempts.md)

## 画面概要

過去の受験履歴を一覧表示する画面。ログイン必須。一覧から選択すると該当の結果画面（S-05）へ遷移する。

## 画面構成要素

| 要素 | 内容 |
| --- | --- |
| 受験履歴一覧 | 受験日時（`submittedAt`）、セクション（`section`）、スコア（`rawScore` / `maxScore`） |
| セクション絞り込み | Reading / Listening / すべて を切り替えるUI |
| ページング | ページ送りUI（`page` / `totalPages`） |

## 入力項目とバリデーション

| 項目 | 種別 | 必須 | バリデーション |
| --- | --- | --- | --- |
| セクション絞り込み | 単一選択 | 任意（未選択時は全件） | `READING` / `LISTENING` / 指定なし |
| ページ番号 | ページング操作 | - | `0`以上の整数（`totalPages`を超えない） |

## 状態・画面遷移

| 操作/状態 | 遷移先・表示 | 条件・備考 |
| --- | --- | --- |
| 画面初期表示 | 一覧を表示（1ページ目、絞り込みなし） | `GET /api/v1/attempts`を呼び出す |
| セクション絞り込み変更 | 一覧を再取得して表示 | 絞り込み条件を付与して再呼び出し |
| ページ送り | 一覧を再取得して表示 | ページ番号を付与して再呼び出し |
| 一覧項目クリック | S-05 結果画面（過去分） | 選択した`attemptId`で結果画面へ遷移する |

## API/データ連携

| API | 用途 | 備考 |
| --- | --- | --- |
| `GET /api/v1/attempts` | 受験履歴一覧の取得（ページング・絞り込み） | [API設計書](https://github.com/h-fujiwara-dev/ielts-creater-backend/blob/main/docs/API設計書/GET_attempts.md) |

## 実装メモ

- **未決事項（backend連携）**: `GET /api/v1/attempts`のAPI設計書にはセクション絞り込み用のクエリパラメータが明記されていない。フロントエンド実装時にbackend側と仕様をすり合わせる必要がある
- **未決事項（ルーティング）**: `GET /api/v1/attempts`のレスポンス項目（`attemptId` / `section` / `submittedAt` / `rawScore` / `maxScore`）には`questionSetId`が含まれない。[docs/画面一覧.md](../画面一覧.md)付録のディレクトリ構成例は結果画面のルートを`/practice/{setId}/result/{attemptId}`としているが、この構成では履歴一覧から結果画面へ遷移する際に`setId`を取得できない。S-05は`attemptId`のみで結果を再取得可能なため、ルーティングを`attemptId`のみに簡素化するか、backend側のレスポンスに`questionSetId`を追加するかを実装時に決定する
