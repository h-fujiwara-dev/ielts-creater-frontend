## 画面概要

本サービスにおけるユーザーデータの取扱い方針を提示する、ログイン不要の静的コンテンツ画面。主にTop画面（S-01）のフッターから遷移する。

本書は**機能仕様（構成要素・遷移条件）のみを扱う**。掲載する本文（条文）は[プライバシーポリシー本文](../legal/プライバシーポリシー.md)を正本とし、本画面はその表示方法を規定する。配色・フォント・具体的なビジュアルレイアウト等のビジュアルデザインは対象外とする。

## 画面構成要素

| 要素 | 内容 |
| --- | --- |
| ページタイトル | 「プライバシーポリシー」 |
| 本文 | [プライバシーポリシー本文](../legal/プライバシーポリシー.md)の内容を章立てのまま表示 |
| 制定日・改定日表示 | 本文冒頭のメタ情報（制定日・最終改定日）を表示 |
| 関連リンク | 利用規約（S-09）への相互リンク、Topへ戻るリンク |
| フッター（SiteFooter共通） | Top画面（S-01）と共通のフッター。Topページ内セクション（特長／使い方／出題形式）へのナビゲーションリンク、プライバシーポリシー/利用規約リンクを含む |

## 入力項目とバリデーション

フォーム入力は持たない。ユーザー操作はリンククリックのみ。

## 状態・画面遷移

| 操作/状態 | 遷移先 | 条件・備考 |
| --- | --- | --- |
| Topフッターのリンク押下 | 本画面 | S-01から遷移 |
| 利用規約リンク押下 | S-09 利用規約画面 | 相互リンク |
| Topへ戻るリンク押下 | S-01 Top画面 | - |

ログイン状態にかかわらず表示可能（未ログイン・ログイン済みの双方からアクセスできる静的画面）。

フッターのTopページ内セクションへのナビゲーションリンクは、本画面（`/privacy`）のようなTop以外のページからでも遷移できるよう、ルート絶対パス+フラグメント形式（例: `/#features`）で実装する。フラグメントのみのリンク（`#features`等）では現在のページ内でしか機能せず、Top以外のページで押下しても遷移しない不具合があったため、`<a>`から`<Link>`への統一とあわせて修正した（[#00069](https://github.com/h-fujiwara-dev/ielts-creater/blob/main/tickets/00069_プライバシーポリシー利用規約画面のフッターヘッダーアンカーリンク不具合修正.md)）。

## API/データ連携

認証不要の静的コンテンツのみで構成され、バックエンドAPIの呼び出しはない。

## 実装メモ

- ルーティングは`app/privacy/page.tsx`（`/privacy`）を想定する
- 本文コンテンツは[docs/legal/プライバシーポリシー.md](../legal/プライバシーポリシー.md)を正本として管理し、実装時にページへ反映する。本文更新時はまず`docs/legal/`側を更新する運用とする
- 実際のページ実装（コーディング）は本チケット（[#00008](https://github.com/h-fujiwara-dev/ielts-creater/blob/main/tickets/00008_プライバシーポリシー利用規約画面の追加.md)）の対象外とし、別途実装チケットで対応する
